# ScholarFlow — Study Plan & Focus Tracker

A lightweight, responsive study planner and Pomodoro focus tracking web application built with vanilla HTML, CSS, and JavaScript.

## Folder Structure

```text
scholarflow/
├── index.html       # Main HTML structure & modals
├── css/
│   └── styles.css   # Responsive layout, light/dark themes, and components
├── js/
│   └── app.js       # State management, CRUD, weekly scheduler, and timer logic
└── README.md        # Setup and usage instructions
```

## How to Run Locally

1. Unzip the downloaded archive to extract the `scholarflow/` folder.
2. Open `scholarflow/index.html` directly in any modern web browser (Chrome, Edge, Safari, Firefox).
3. All tasks, subjects, and logged study hours are automatically saved in your browser's `localStorage`.

## How to Host Online (Free)

- **Netlify Drop:** Drag and drop the extracted `scholarflow/` folder onto [app.netlify.com/drop](https://app.netlify.com/drop) to get an instant public HTTPS URL.
- **GitHub Pages:** Upload the contents of `scholarflow/` to a GitHub repository and enable GitHub Pages in **Settings → Pages**.
